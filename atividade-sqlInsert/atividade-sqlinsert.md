## Exercício 3

```sql
CREATE TABLE produto (
    id_produto   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome         VARCHAR(150) NOT NULL,
    preco        NUMERIC(10, 2) NOT NULL CHECK (preco >= 0),
    estoque      INTEGER NOT NULL DEFAULT 0 CHECK (estoque >= 0),
    id_categoria BIGINT NOT NULL,
    CONSTRAINT fk_produto_categoria
        FOREIGN KEY (id_categoria)
        REFERENCES categoria (id_categoria)
);
```

## Exercício 15

O Postgres não deverá aceitar o resultado, pois foi definido que `nome` não pode ser vazio.

```sql
INSERT INTO produto (preco, estoque, id_categoria)
VALUES (10.00, 10, 7);
```

Erro retornado:

```
Failed to run sql query: ERROR:  23502: null value in column "nome" of relation "produto" violates not-null constraint
DETAIL:  Failing row contains (8, null, 10.00, 10, 7, null).
```

Restrição responsável:

```sql
nome         VARCHAR(150) NOT NULL,
```

## Exercício 17

O banco não deve aceitar, pois não existe categoria 9999.

```sql
INSERT INTO produto (nome, preco, estoque, id_categoria)
VALUES ('Monitor', -500.00, 10, 9999);
```

`id_categoria = 9999`. Se não existir uma categoria com esse id, isso viola a chave estrangeira `fk_produto_categoria`.
